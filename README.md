# Portfolio — Jayden Akoi

Portfolio de BTS SIO (option SLAM) : projets, procédures, compétences et parcours.

- Site statique (HTML, CSS, JavaScript natif), aucune dépendance.
- Pour le voir : ouvrir `index.html` dans un navigateur, ou l'activer avec GitHub Pages.

## Ajouter un projet ou une procédure

Tout le contenu des projets et des procédures se trouve dans `assets/js/data.js`.
Copier le modèle commenté, le remplir : la carte, la fenêtre de détail et la ligne
du tableau de synthèse BTS sont générées automatiquement.

## Structure

```
index.html
assets/
  css/style.css   charte « ardoise & cuivre » et animations
  js/data.js      contenu : projets, procédures, compétences du bloc 1
  js/main.js      rendu et interactions
  img/            images
  docs/           CV, lettre de motivation, procédures, cahiers des charges (PDF)
```
